计算机科学是一门极其广阔的学科。全球分布式系统、人工智能、机器人、图形学、安全、科学计算、计算机架构，还有几十个新兴子领域，每年都在涌现新技术、新发现。计算机科学发展得太快，人类生活几乎没有哪个方面能躲开它的影响。商业、通信、科学、艺术、休闲与政治，都被计算重新塑造。

计算机科学能有如此高的生产力，正因为它建立在一套优雅而强大的基本思想之上。一切计算，都从三件事开始：表示信息，规定处理信息的逻辑，再设计抽象来管住这套逻辑的复杂度。要掌握这些基本原理，我们就得准确理解计算机是怎么解释程序、怎么执行计算的。

这些基本思想，长期以来都靠一本经典教材来传授：Harold Abelson、Gerald Jay Sussman 与 Julie Sussman 合著的《计算机程序的构造与解释》（Structure and Interpretation of Computer Programs，简称 SICP）。本书大量借鉴了这本教材，原作者也已慷慨授权，允许在 Creative Commons 许可下改编和重用。本书自己也按 [Creative Commons 署名-非商业性使用-相同方式共享 3.0 许可协议](http://creativecommons.org/licenses/by-nc-sa/3.0/deed.en_US) 发布。

## 1.1.1 Python 编程

> 语言与其说是用来学的，不如说是用来加入的。
>
> —— [Arika Okrent](http://arikaokrent.com/)

要定义计算过程，我们需要一门编程语言，最好是很多人都能理解、各种计算机也都能理解。本书主要使用 [Python](http://docs.python.org/py3k/)。

Python 是一门应用很广的编程语言，吸引了各行各业的人：Web 程序员、游戏工程师、科学家、学者，甚至新编程语言的设计者。学了 Python，你就加入了上百万人的开发者社区。这样的社区很重要——成员互相帮忙解决问题，分享项目和经验，一起开发软件和工具。肯投入的人，往往凭贡献赢得声望和尊重。

Python 语言本身，就是[一个庞大的志愿者社区](http://www.python.org/psf/members/)的成果。这个社区引以为傲的，是贡献者的[多元化](http://python.org/community/diversity/)。这门语言由 [Guido van Rossum](http://en.wikipedia.org/wiki/Guido_van_Rossum) 在 20 世纪 80 年代末构思并首次实现。他在 [Python 3 教程](http://docs.python.org/py3k/tutorial/appetite.html) 的第一章里解释了，Python 为什么能在当今这么多语言中如此受欢迎。

Python 是很出色的教学语言，因为一直以来，Python 的开发者都强调代码要便于人类理解，并在 [Python 之禅](http://www.python.org/dev/peps/pep-0020/) 里定下了「美观、简洁、可读」的原则。Python 特性宽泛，能支持多种编程风格，因此很适合本书，这些风格我们会逐一探讨。Python 编程没有唯一的方式，但开发者社区共享一套约定，有助于阅读、理解和扩展已有的程序。Python 既灵活又易上手，学生可以借此探索各种编程范式，再把学到的东西用到数以千计的[进行中的项目](http://pypi.python.org/pypi)上。

本书继承了 [SICP](http://mitpress.mit.edu/sicp) 的精神：在介绍 Python 特性的同时，也讲抽象技术和严谨的计算模型。此外，本书还是 Python 编程的实用入门，涵盖一些高级语言特性和示例。随着你读下去，你对 Python 的掌握会自然而然提高。

开始学 Python 编程，最好的方式就是直接和解释器打交道。本节介绍如何安装 Python 3、启动交互式会话，然后开始编程。

## 1.1.2 安装 Python 3

和所有优秀的软件一样，Python 有很多版本。本书使用 **Python 3 的最新稳定版**。许多电脑已经装了旧版 Python，比如 Python 2.7，但它们和本书的描述对不上。你可以用任何一台电脑，只是要做好自己安装 Python 3 的准备。（别担心，Python 免费。）

你可以从 Python 下载页面下载 Python 3，点击以 3 开头（不是 2）的版本，然后按安装程序的说明完成安装。

需要更多帮助的话，可以看看 Julia Oh 制作的 [Windows 安装](http://www.youtube.com/watch?v=54-wuFsPi0w) 和 [Mac 安装](http://www.youtube.com/watch?v=smHuBHxJdK8) 视频教程。

## 1.1.3 交互式会话

在 Python 交互式会话中，你在提示符 `>>>` 后输入一些 Python 代码。Python 解释器读取并执行你输入的内容，完成你的各种命令。

要启动交互式会话，先运行 Python 3 应用程序：在终端（Mac/Unix/Linux）里输入 `python3`，或者在 Windows 里打开 Python 3 应用程序。

看到 Python 提示符 `>>>`，就说明交互式会话启动成功了。本书用提示符加上一些输入来展示示例交互。

```py
>>> 2 + 2
4
```

**交互控制**：每个会话都会保存你输入过的历史。按 `<Control>-P`（上一条）和 `<Control>-N`（下一条）就能翻阅；按 `<Control>-D` 退出会话，并丢弃这段历史。在某些系统上，上下方向键也能循环翻阅历史。

## 1.1.4 第一个例子

> 想象赋予未知之物以形，
>
> 诗人的笔又把它们描画成相，
>
> 给虚无缥缈之物，
>
> 一处居所、一个名字。
>
> —— William Shakespeare《仲夏夜之梦》

为了正式介绍 Python，我们先看一个用到几项语言特性的例子。下一节我们会从头开始，一点一点把语言搭起来。本节可以看作后面特性的抢先预览。

Python 内置支持许多常见编程活动，比如处理文本、显示图形、通过互联网通信。下面这行代码：

```py
>>> from urllib.request import urlopen
```

是一条 `import` 语句，它导入访问网络数据的功能，其中有一个叫 `urlopen` 的函数，可以访问统一资源定位符（URL，即互联网上某个内容的位置）指向的内容。

**语句与表达式**。Python 代码由表达式（expressions）和语句（statements）组成。广义上说，计算机程序的指令无非两类：

1. **计算某个值**
2. **执行某个操作**

**语句**通常描述**操作**：Python 解释器每执行一条语句，计算机就执行相应的操作。而**表达式**通常描述**计算**：Python **求值**（evaluates）一个表达式，就是在算出它的值。本章会介绍几种不同类型的语句和表达式。

这条**赋值语句**（assignment statement）：

```py
>>> shakespeare = urlopen('http://composingprograms.com/shakespeare.txt')
```

把名称 `shakespeare` 与等号 `=` 后面表达式的值关联起来。该表达式把 `urlopen` 函数应用在一个 URL 上，这个 URL 的内容是莎士比亚 37 部戏剧的完整文本，全部收在一个文件里。

**函数**。函数封装了**操纵数据的逻辑**。`urlopen` 就是一个函数：网址是一段数据，莎士比亚的戏剧文本是另一段数据。从前者到后者，过程可能很复杂，但只要一个简单的表达式就能完成，因为复杂性都收进了函数内部。**函数是本章的主题**。

另一条赋值语句：

```py
>>> words = set(shakespeare.read().decode().split())
```

把 `words` 与莎士比亚戏剧中出现过的所有不重复单词关联起来，一共 33,721 个。`read`、`decode`、`split` 这一串命令，每一个都作用于一个**中间计算实体**：先从打开的 URL 读取数据，再把数据解码成文本，最后把文本拆成单词。这些单词全部放进一个**集合**。

**对象**。**集合**（set）是一种对象（object），支持求交集、判断成员关系等集合操作。对象把数据和操纵数据的逻辑**紧密结合**在一起，两者的复杂度也就一并管住了。对象是第二章的主题。最后，这个表达式：

```py
>>> {w for w in words if len(w) == 6 and w[::-1] in words}
{'redder', 'drawer', 'reward', 'diaper', 'repaid'}
```

是一个**复合表达式**，它求值得到莎士比亚戏剧中所有**反过来拼也是单词**的单词集合。神秘符号 `w[::-1]` 表示逐个枚举单词里的字母，其中 -1 表示反向步进。你在交互式会话里输入一个表达式，Python 会在下一行**打印它的值**。

**解释器**。要对复合表达式求值，就得有一套**精确的流程**，能按可预测的方式解释代码。实现这套流程、对复合表达式求值的程序，就叫解释器。解释器的设计与实现是第三章的主题。

编程语言的解释器，独特之处就在于它足够**通用**。Python 设计时并没有考虑莎士比亚，但它足够灵活，让我们只用几条语句和表达式就处理了大量文本。

最后我们会发现，这些核心概念紧密相关：**函数是对象，对象是函数，解释器则是两者的实例**。但要真正掌握编程这门手艺，还得逐个搞清楚每个概念，以及它们在组织代码时各自的作用。

## 1.1.5 错误

Python 正等着你下命令。哪怕你还不熟悉它的全部词汇和结构，我们也鼓励你动手试试。当然，也要做好出错的准备：计算机快得惊人、灵活得惊人，却也极其死板。[斯坦福大学的入门课程](http://web.stanford.edu/class/cs101/code-1-introduction.html)这样描述**计算机的本质**：

> 计算机的基本等式是：`computer = powerful + stupid`
>
> 计算机非常强大，能飞快地浏览海量数据，每秒执行数十亿次运算，而每次运算都很简单。
>
> 计算机也蠢得惊人、脆弱得惊人。它能做的运算极其死板、简单、机械。计算机没有半点真正的洞察力……它绝不是电影里的 HAL 9000。至少有一点你可以放心：别把它当成某种大脑而心生畏惧，说到底，它非常机械。
>
> 编程，就是人用自己的洞察力，拿计算机能做的这些琐碎、简单的小操作，搭出有用的东西。
>
> —— Francisco Cai 与 Nick Parlante，斯坦福 CS101

你一上手 Python 解释器，就能立刻体会到它的死板：哪怕只是拼写或格式上最小的改动，也会带来意料之外的输出和错误。

学着看懂错误、找出错误的原因，就叫**调试**（debugging）。调试有几条指导原则：

1. **增量测试**（Test incrementally）：写得好的程序，都由小的模块化组件构成，每个组件都能单独测试。你写一段就尽早测一段，以便早发现问题，也对组件更有信心。
2. **隔离错误**（Isolate errors）：某条语句输出里的错误，通常能归到某个具体的模块化组件上。诊断问题时，先把错误追到你能找到的最小代码片段，再去纠正它。
3. **检查假设**（Check your assumptions）：解释器会一字不差地执行你的指令——不多也不少。当代码的行为和程序员以为的不一致时，输出就显得出乎意料。先明确你的假设，再把调试的力气花在验证假设是否真的成立上。
4. **请教别人**（Consult others）：你不是一个人！看不懂错误信息，就问朋友、老师或搜索引擎。如果已经定位到错误却不知道怎么改，就请别人帮你看一眼。小组一起解决问题的过程里，能分享到很多宝贵的编程知识。

**增量测试、模块化设计、精确假设和团队合作**是贯穿本书的主题，希望它们也能贯穿你的整个计算机科学之路。
