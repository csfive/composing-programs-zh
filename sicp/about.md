# 关于

《Composing Programs》是一本免费的在线编程与计算机科学入门教材。它承袭 [SICP](https://book.douban.com/subject/1148282/) 的传统，着重讲抽象方法、编程范式，以及驾驭大型程序复杂度的技术，主要用 Python 3 来讲解这些概念。

本站是它的中文译本，由 [CS Five](https://github.com/csfive) 维护，全书 4 章 29 节均已译完。

## 翻译

- 术语以 [Python 中文文档](https://docs.python.org/zh-cn/3/glossary.html) 与 SICP 中译本为准，完整术语表见 [GLOSSARY.md](https://github.com/csfive/composing-programs-zh/blob/main/GLOSSARY.md)。
- 风格约定、常见翻译腔清单见 [TRANSLATION.md](https://github.com/csfive/composing-programs-zh/blob/main/TRANSLATION.md)。
- 书中代码块保留原有标识符与执行输出，注释和文档字符串译为中文。
